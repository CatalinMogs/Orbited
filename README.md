# Orbited

2D Newtonian gravity simulator, it simulates gravitational interactions between planets and a central star, calculating planetary movement based on mass, velocity and gravity.

## Features

<ul>
  <li>Add and select planets</li>
  <li>Adjust planet mass and velocity.</li>
  <li>Display planetary trails.</li>
  <li>Simulate interactions</li>
  <li>Pause, resume and reset the simulation.</li>
</ul>
